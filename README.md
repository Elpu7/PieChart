PieChart is a small client-side mod that lets you open Minecraft's debug pie chart with a normal keybind instead of using `F3 + 1`.

It also includes an editor mode where you can move and scale the pie chart on screen to fit your HUD layout.

## Features

- Toggle the debug pie chart with a configurable keybind
- Open the editor through Mod Menu or a separate keybind
- Drag the pie chart to reposition it
- Resize the pie chart with live preview
- Client-side only

## Default keybinds

- `F8` - Toggle pie chart
- `F7` - Open pie chart editor

## Requirements

### Fabric

- [Fabric API](https://modrinth.com/mod/fabric-api)
- [Elib](https://modrinth.com/mod/elib)
- [Mod Menu](https://modrinth.com/mod/modmenu) (optional)

### NeoForge

- [Elib](https://modrinth.com/mod/elib)

### Quilt
